La nostra proposta de projecte, EasyAssist, és una plataforma web pensada per ajudar les persones a resoldre problemes bàsics de tecnologia d’una manera senzilla, ràpida i guiada.

La idea principal és que qualsevol usuari, encara que no tingui coneixements tècnics, pugui seguir un conjunt de preguntes pas a pas que el portin a identificar el problema i aplicar una possible solució. En el cas de problemes de connexió a internet, per exemple, la web guia l’usuari des de comprovacions bàsiques (com el router o el cablejat) fins a solucions més avançades (com el reinici o el reset del dispositiu).

La proposta es basa en fer un sistema molt intuïtiu, on l’usuari no hagi de buscar informació per la seva compte, sinó que la mateixa eina el vagi dirigint segons les seves respostes. D’aquesta manera es redueix la confusió i s’agilitza la resolució del problema.

A més, es planteja una interfície clara i visual, amb botons grans i llenguatge senzill, pensada especialment per facilitar l’ús a persones amb poca experiència tecnològica.

En resum, EasyAssist proposa una forma més accessible i ordenada de solucionar problemes tecnològics habituals, evitant passos innecessaris i millorant l’experiència de l’usuari.
